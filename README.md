# Vehicle Cost Calculator 🚚

A beginner-friendly Python project that calculates vehicle diesel consumption and trip cost.

## Features

- Calculate diesel used
- Calculate diesel cost
- User input from terminal
- Uses variables, data types, arithmetic operators, and functions like `input()` and `print()`

## Technologies Used

- Python 3.12
- VS Code
